记分 / 牌力 / 术语
三 Tab 需求方案

在现有「德州记分」工具上扩展查阅能力：保留完整记分流程， 新增「牌力」排序说明与「术语」科普，三者以顶部全局 Tab切换。 纯前端静态内容，无云端、无后端。

v0.2 审查合入摘要

布局分区写死（Tab / 一手·汇总 / 底栏与 padding）； 牌力页头措辞修正；花色无大小升为 P0； Wheel 钉死 5-high；切 Tab 前 blur 输入； 术语词条微调；牌力 example 字段规范；进 Tab 重置滚动； aria 约定；部署缓存确认。

1背景与目标

1.1 背景

当前应用聚焦家庭局/朋友局记分结算（买入、剩余、结果、校验、分享）。 现场常出现：牌型谁大谁小说不清、术语听不懂（盲注、位置、翻牌等）。 希望在同一应用内提供轻量查阅，不必另开网页或搜图。

1.2 目标

  • 提供稳定入口，用 三个 Tab 组织：记分、牌力、术语。
  • 「牌力」按从大到小列出标准德州牌型，并明确点数大小关系（含 A-5 顺与 10–A 高牌区间的说明）。
  • 「术语」覆盖操作、位置、发牌相关常用词，中文为主、可附英文缩写。
  • 记分能力与数据行为不回退：切换 Tab 不丢记分状态；持久化规则不变。

1.3 成功标准（产品）

  • 新手能在 10 秒内找到「同花和顺子谁大」。
  • 能说清「A 什么时候最大、什么时候可以当 1」。
  • 记分员切去查牌力/术语后，回到记分页数据仍在。

2范围与非目标

2.1 本版范围内（In Scope / P0）

  • 全局三 Tab 导航与写死的壳层布局（见 §3）。
  • 记分 Tab：现有功能整体迁入（买入/剩余/结果/校验/排序/分享/清空等）。
  • 牌力 Tab：10 级牌型列表 + 点数大小 + 特殊顺子 + 花色无大小。
  • 术语 Tab：分组词条（操作 / 位置 / 发牌与街道），只读列表。
  • 竖屏优先；内容可滚动；无账号、无服务端。
  • 切 Tab 时记分输入 commit；各查阅 Tab 进入时滚动置顶。

2.2 本版不做（Out of Scope）

  • 牌力计算器 / 胜率模拟 / 起手牌矩阵训练。
  • 视频教学、长文攻略、多语言完整 i18n。
  • 术语搜索、收藏、用户自定义词条（P1）。
  • 云端同步词条；与记分结果联动判定牌型。
  • 改动部署架构（仍 dist + Nginx；index.html no-cache 见部署方案）。
  • 「现金桌 / 锦标赛 / 抽水」等场外词（默认不做；若加单独「场外」组 ≤3 条）。
  • Straddle / 枪口强制加注等低频词（P0 不进；可选 P1）。
  • 边池计算（仅允许名词解释）。

4Tab「记分」

行为与现网一致，整体作为「记分」Tab 的内容区挂载，不删减已验收能力。

  • 一手配置；人员增删改；买入 ± / 手输；剩余手输；结果只读与红绿。
  • 校验、总人数/总筹码/结果合计、排序、清空人员/记分、分享图、本地持久化。
  • 底栏自适应（添加 / 校验 / 更多）仅在记分 Tab 展示。
切换保护（P0 必做）
  • 从记分切到牌力/术语再切回：列表数据、一手、排序模式均保持；不触发清空或错误地重新 load 默认空状态。
  • 离开记分 Tab 前：对当前焦点输入控件执行 blur（或等价 commit），使 IntegerField 等中间 draft 落库，避免 draft 与 store 短暂不一致。
  • 切回记分时不必强制滚动置顶（保留用户上次看列表的位置更友好）；若实现成本高，P0 可接受整页内容区统一行为，但数据不得丢。

5Tab「牌力」

5.1 页面结构（自上而下）

  1. 页头说明（必做）——采用以下语义（措辞可微调，不得暗示「不比公共牌」）：
    标准页头文案

    以下为德州扑克摊牌时，标准五张牌型由强到弱的顺序 （每人用手牌 + 公共牌凑成的最佳五张）。本表用于比牌型强弱，非起手牌推荐。

  2. 点数大小说明卡片（必做，置顶）：见 5.2。
  3. 花色无大小（P0 必显）：见 5.2 末行，可并入点数卡片或紧随其后。
  4. 特殊顺子说明（必做）：见 5.3。
  5. 牌型列表：从大到小 10 档，见 5.4；每档含 example 示意。
  6. 比大小短提示 + 页脚小字：见 5.5。

5.2 点数大小关系（需求硬点）

必须明确展示

说清 【9、10、J、Q、K】 与 【A、2、3、4、5】 相关大小， 避免「A 到底大还是小」混乱。

主题说明要点
常规点数序（高→低） A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3 > 2。
K、Q、J、10、9 属高点侧；5、4、3、2 属低点。 单独比高牌时，A 最大。
10 / J / Q / K K > Q > J > 10 > 9。 均高于 8 及以下；成顺时按连续关系，不是「字母比数字」。
A 的双重身份 多数情况 A 最大。
仅在 A-2-3-4-5（轮子）中 A 当作 1，该顺是最小的顺子。
A 不能两边用：不存在 Q-K-A-2-3 顺子。
与 9–K 对照 单牌：A 大于 K/Q/J/10/9。
顺子：先比顶端（如 10-J-Q-K-A 顶为 A，大于 9-10-J-Q-K 顶为 K）。
花色无大小（P0 必显） 标准规则下花色无大小；同牌型比点数与踢脚，不比花色 （避免「黑桃大于红桃」争执）。

5.3 两种关键顺子对照

顺子 牌面示例 A 的角色 大小关系
最大顺（Broadway） 10 · J · Q · K · A A 作最大 顺子中最大
最小顺（轮子 / Wheel） A · 2 · 3 · 4 · 5 A 作 1 顺子中最小；仍大于「仅高牌」。
比两个顺子时：A-2-3-4-5 视为 5-high 顺，小于 6-high 顺（2-3-4-5-6）。

对照句：10-J-Q-K-A ＞ 9-10-J-Q-K ＞ … ＞ A-2-3-4-5（在「都是顺子」的前提下）。

5.4 牌型列表（从大到小，10 档）

配置建议统一字段（P0 示意用文字花色即可，如 A♠）：

5.5 同牌型短提示（列表底）

  • 同牌型先比主牌点数，再比踢脚；
  • 同花比点不比花色；
  • 顺子比最高张；A-2-3-4-5 的「高」按 5 计（5-high），小于 2-3-4-5-6。

页脚：仅供朋友局参考；场地另有约定（如特殊玩法）时以现场规则为准。

6Tab「术语」

6.1 目标

分组解释朋友局高频说法。偏操作 / 位置 / 发牌与街道，不展开职业深度策略。验收不要求会算边池。

A. 操作相关

术语说明要点
跟注 Call投入与当前需跟金额相同的筹码，不加注。
加注 Raise在跟注基础上提高下注额。
再加注 Re-raise在已有加注后再提高。
过牌 Check当前无人下注时选择不下注并保留行动权。
弃牌 Fold放弃本手牌，不再争夺底池。
全下 All-in把剩余筹码一次性押上。
盲注 Blind发牌前强制注（小盲/大盲）。
前注 Ante部分规则下每人都先投一点；朋友局不一定有。
底池 Pot桌面累积、供赢家拿走的筹码。
边池 Side pot有人全下后形成的额外池。本版仅名词解释，验收不算边池。
摊牌 Showdown最后一轮下注结束，未弃牌者比牌。
亮牌 / 埋牌 摊牌时出示手牌，或选择不展示。 赢了也可以埋牌（朋友局常见礼仪：不强求亮给别人看）。

B. 位置相关

术语说明要点
庄位 Button / BTN经销按钮位；盲注圈后通常最后行动，位置较优。
小盲 SB庄位左手，强制小盲。
大盲 BB小盲左手，强制大盲。
枪口 UTG大盲左手，翻前较早行动。
中间位 MP枪口与后位之间的笼统叫法。
关煞 / 劫位（Cutoff / CO） 庄位右手；后位，可较多偷盲。中文「关煞/劫位」保留，括注 Cutoff。
前位 / 后位（位置优势） 前位行动早、信息少；后位行动晚、信息多。 位置只影响「谁先说话」，不改变公共牌本身 （原「共同牌位置感」并入本条，不再单列怪词条）。

C. 发牌与街道

术语说明要点
底牌 / 手牌 Hole cards每人私有的两张牌（标准德州）。
公共牌 Community cards桌面共用、可用来组成五张牌的牌。
翻前 Preflop发公共牌前，只有手牌的阶段。
翻牌 Flop三张公共牌；进入翻牌圈。
转牌 Turn第四张公共牌。
河牌 River第五张公共牌，最后一轮下注。
烧牌 Burn发公共牌前弃掉最上一张；朋友局或简化。
成牌 / 听牌已成型 vs 再一张可能成型（如听同花）。
公共牌面 Texture是否连张、是否双色等，科普级一句即可。
发牌顺序通常自小盲起顺时针发手牌；庄钮每手移动。

6.3 交互

  • 分组标题清晰分隔；词条「标题 + 正文」列表；全文可纵向滚动。
  • P0 不做搜索；不做编辑/收藏。
  • 进入术语 Tab 时内容区滚动重置到顶部（P0）。

7全局交互与导航

7.1 Tab 位置与壳层

  • 已拍板：顶部全局 Tab，始终在最上方（见 §3）。
  • 选中态明显；触控热区高度 ≥ 40px。

7.2 与底栏 / padding

  • 仅记分 Tab 显示原固定底栏。
  • 牌力、术语：隐藏底栏，且 去掉 为底栏预留的 padding-bottom，避免大块空白。

7.3 滚动

  • P0：每次切入「牌力」或「术语」时，该 Tab 内容滚动到顶部。
  • P1 可选：各 Tab 记忆 scrollTop。

7.4 无障碍（P0 基线）

  • 使用 role="tablist" / tab / tabpanel"。
  • 选中 Tab：aria-selected="true"；关联 aria-controls 与 panel 的 id。
  • P1 可选：键盘左右方向键切换 Tab。

8视觉与内容规范

  • 延续现有暗色主题；中文为主，英文小字辅助。
  • 牌力序号 1–3 可用强调色。
  • P0 牌面示意：文字花色（A♠ K♥…），不依赖外网图；精美牌面组件 P1。
  • 文案朋友局口语化、短句。

9数据与实现建议

  • 无后端：handRanks.ts（含 rank/nameZh/nameEn/example/note）、glossary.ts（分组词条）。
  • UI 状态：activeTab: 'score' | 'ranks' | 'terms'；记分仍 useScoreStore。
  • 离开记分 Tab：先 blur 活动输入再切换。
  • P0 可不引入 React Router。
  • 测试：Tab 切换数据保留；blur 后数值已 commit；牌力含 A/ wheel / 花色无大小文案；术语无「共同牌位置感」独立条；进牌力/术语 scrollTop=0。
  • 部署：静态文案变更，仍 git pull && ./scripts/deploy.sh；依赖现有 index.html no-cache + assets 长缓存即可。

10验收标准

  • 三 Tab 可见；默认记分；全局 Tab 在最顶。
  • 记分：一手/汇总/列表/底栏齐全；功能与改版前一致。
  • 牌力/术语：无一手、无汇总、无记分底栏；无多余底栏 padding 空白。
  • 切换后回记分，数据不丢；输入中途切走再回来无脏 draft 异常。
  • 牌力页头为「手牌+公共牌最佳五张」语义；含点数序、A 双重身份、wheel 5-high < 6-high、禁 Q-K-A-2-3、花色无大小。
  • 10 档从大到小且每档有 example 文字牌面。
  • 术语三组齐全；含亮牌/埋牌礼仪；边池仅解释；无独立「共同牌位置感」怪词条。
  • 进入牌力/术语时列表在顶部；竖屏可滚动。
  • Tab 具备基本 aria（selected / controls）。
